# TestTools Android v1.8

TestTools Android 首次公開版本，整合手機測試、快速截圖與影音備份所需的常用工具。

## 本版功能

- **常用測試素材**：同步雲端資料庫清單，快速開啟圖片、影片、音訊與測試檔案，並支援離線快取。
- **常用程式**：從雲端資料庫清單開啟常用工具、網站與下載頁面。
- **測試亮度**：支援方形／圓形、可自訂及刪除白色顯示比例、最高亮度、保持喚醒、滑動切換與設定自動保存。
- **浮動快速截圖**：浮動按鈕顯示時間與電量，點一下保存截圖，並提供閃光、震動、提示音與成功動畫。
- **影音快速備份**：透過 LocalSend 或 USB 外接磁碟備份 `DCIM`／`Pictures`，支援增量紀錄、背景傳輸及失敗重試。

## 安裝方式

1. 下載 Release 附件 `TestTools-Android-v1.8.apk`。
2. 將 APK 開啟並允許此來源安裝應用程式。
3. 依實際使用的功能授予媒體、檔案、浮動視窗或無障礙服務權限。

最低支援 Android 8.0（API 26）。

## 使用提醒

- Android 11 以上的浮動截圖需先開啟「TestTools 浮動快速截圖」無障礙服務。
- Android 8～10 每次建立螢幕擷取工作階段時需接受一次系統授權。
- 銀行、DRM 串流、無痕模式等受保護畫面可能禁止截圖。
- 截圖保存於手機的 `Pictures/TestTools Captures`，TestTools 不會自動上傳圖片。
- 本 Release 提供的是 Debug 簽署 APK，適合目前測試及內部使用。
